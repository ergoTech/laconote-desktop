# Laconote Desktop

AI meeting recorder for macOS. Captures system audio + microphone natively — no browser extension needed.

## Download

**[Download latest release](https://github.com/ergoTech/laconote-desktop/releases/latest)**

- `Laconote_0.1.6_aarch64.dmg` — DMG installer
- `Laconote_0.1.6_macos_aarch64.app.zip` — ZIP archive

## Features

- **System audio capture** — Records Zoom, Google Meet, Teams, Discord and any other app
- **Microphone recording** — Captures your voice alongside remote participants
- **Google Calendar sync** — Reminders before meetings, auto-detect meeting links
- **Meeting auto-detection** — Detects when Zoom, Teams, Discord, Slack starts
- **8 languages** — English, Українська, Русский, Deutsch, Français, Español, Italiano, Polski

## Requirements

- macOS 14.2+ (Apple Silicon & Intel)
- [Laconote account](https://laconote.com)
